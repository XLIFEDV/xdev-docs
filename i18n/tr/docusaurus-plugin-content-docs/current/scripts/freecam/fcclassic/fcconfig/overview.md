# Konfigürasyon Genel Bakış

Freecam Classic’in tüm davranışları `config.lua` dosyası üzerinden kontrol edilir.

Bu bölümde aşağıdaki konular ele alınmaktadır:

- Kurulum sırası ve önerilen `server.cfg` yapılandırması
- Sistem ayarları (zoom, mesafe, hız çarpanları, reset davranışı)
- Aktivasyon seçenekleri (komut / tuş / basılı tutma)
- Takip sistemi davranışı (kameranın oyuncuya bağlı çalışması)
- Override doğrulama mekanizması
