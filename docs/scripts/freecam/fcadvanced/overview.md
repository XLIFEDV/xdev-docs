# Advanced Freecam

Advanced Freecam is an extended cinematic camera system built on top of the **Classic Freecam** core.

It expands the original free camera functionality by introducing a full **visual control layer**, allowing developers and creators to manipulate camera behavior, scene visuals, and cinematic effects directly through an integrated UI.

While Classic Freecam focuses on providing a lightweight and developer-friendly free camera system, **Advanced Freecam transforms it into a complete cinematic toolkit** designed for recording, screenshots, and scene composition.

---

# Core Concept

Advanced Freecam keeps the same **core camera architecture** as Classic Freecam while adding multiple new systems designed for visual control and scene management.

The system allows developers to control:

- camera movement parameters
- visual scene settings
- cinematic effects
- environmental conditions
- camera behavior and UI interactions

All of these systems are configurable and can be integrated into existing server environments.

---

# Relationship with Classic Freecam

Advanced Freecam is not a separate camera implementation.

Instead, it is built **on top of the Classic Freecam core**, meaning:

- the base camera logic remains the same
- configuration structure stays familiar
- existing integrations continue to work
- developers already using Classic Freecam can adopt Advanced Freecam easily

Advanced Freecam simply **extends the capabilities of the base system**.

---

# Key Features

## Integrated UI Control Panel

Advanced Freecam introduces a fully integrated UI that allows users to adjust camera parameters and visual settings in real time.

This includes controls for:

- camera movement speed
- rotation sensitivity
- zoom behavior
- cinematic visual options

---

## Visual Scene Control

The system allows full **local visual scene customization**, including:

- time control
- weather control
- motion blur
- camera shake
- depth of field
- cinematic mode

All visual changes are applied **locally**, meaning they do not affect other players on the server.

---

## Camera Effects & PostFX

Advanced Freecam supports multiple **visual filters and cinematic effects** that can be applied directly to the camera.

These effects can be used to:

- enhance lighting and atmosphere
- create cinematic color grading
- simulate film-style visuals
- prepare scenes for screenshots or recordings

---

## Persistent Settings

Camera configurations can optionally be **saved and restored**.

This allows creators to:

- reuse camera setups
- maintain consistent cinematic scenes
- reduce setup time for repeated recordings

---

## Developer Friendly Architecture

Advanced Freecam keeps the same **override architecture** introduced in Classic Freecam.

Developers can override internal systems such as:

- camera logic
- notifications
- screenshot capture
- visual effects behavior

This makes the system easy to integrate into custom frameworks or existing server environments.

---

# Who is this for?

Advanced Freecam is designed for:

- **content creators**
- **cinematic recording**
- **screenshot capture**
- **scene composition**
- **developers needing visual camera tools**

If you require more than a simple free camera and need a **complete cinematic control system**, Advanced Freecam provides the necessary tools.
