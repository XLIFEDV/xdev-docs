# Differences from Classic

Advanced Freecam is built on top of the **Classic Freecam** core.  
While Classic Freecam focuses on providing a lightweight and developer-friendly free camera system, Advanced Freecam expands this foundation by introducing **visual control systems and cinematic features**.

Both systems share the same **core camera architecture**, but Advanced Freecam includes additional layers designed for recording, screenshots, and cinematic scene creation.

---

# Core Differences

The main differences between **Classic Freecam** and **Advanced Freecam** are related to visual control and user interaction.

| Feature | Classic Freecam | Advanced Freecam |

| Core Freecam Movement | ✔ | ✔ |
| Camera Rotation & Zoom | ✔ | ✔ |
| Visibility Guard | ✔ | ✔ |
| UI Control Panel | ❌ | ✔ |
| Visual Scene Controls | ❌ | ✔ |
| Time Control | ❌ | ✔ |
| Weather Control | ❌ | ✔ |
| Camera Effects | ❌ | ✔ |

---

# UI Integration

Classic Freecam operates primarily through **controls and configuration**.

Advanced Freecam introduces a **fully integrated UI system** that allows users to adjust camera and scene parameters in real time.

This UI provides access to:

- movement settings  
- rotation speed  
- zoom behavior  
- visual effects  
- environmental controls  

---

# Visual Scene Systems

Advanced Freecam adds multiple systems designed for **cinematic scene control**, including:

- local time control
- local weather control
- camera shake effects
- motion blur
- depth of field
- cinematic mode

These systems are applied **locally** and do not affect the global server environment.

---

# Post Processing Effects

Advanced Freecam introduces **PostFX and camera effects** which allow creators to modify the visual appearance of the scene.

These effects can be used to create:

- cinematic lighting
- film-style visuals
- atmospheric scenes
- enhanced recordings and screenshots

---

# Persistent Camera Settings

Unlike Classic Freecam, Advanced Freecam allows camera settings to be **saved and restored**.

This enables creators to reuse specific camera setups without manually reconfiguring them every time the camera is activated.

---

# Developer Integration

Advanced Freecam keeps the same **override architecture** used in Classic Freecam.

Developers can override internal behavior such as:

- camera actions
- notifications
- visual systems
- screenshot handling

This ensures that Advanced Freecam can be integrated into **custom frameworks and server environments** without modifying the core resource.

---

# Summary

Classic Freecam provides the **core camera functionality**.

Advanced Freecam builds on top of that core and introduces **cinematic tools, visual controls, and UI-driven configuration**, transforming the system into a complete **scene creation and recording toolkit**.
