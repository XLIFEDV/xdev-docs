# Freecam Classic

Freecam Classic is a lightweight Freecam system designed for fast deployment.

It focuses on:

- Command / key / hold based activation (`Config.System.action`)
- Camera movement, rotation and zoom
- Player-follow camera behavior via entity attachment
- Validation checks (dead / vehicle / custom)
- Exports for integration (`openFreecam`, `closeFreecam`, `getData`)

This edition is intended for users who do not need a menu or photo tools.
